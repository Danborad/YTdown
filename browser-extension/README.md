# YT下载器 Cookie Sync

1. 打开桌面版 `YT下载器`
2. 在“Cookie 配置”中复制配对码
3. 打开 Chrome/Edge 的扩展管理页，开启开发者模式
4. 选择“加载已解压的扩展程序”，指向当前文件夹
5. 打开插件，输入配对码后点击“连接并同步”

同步成功后，插件会在 Cookie 变化时自动重新同步。

如果默认端口 `38491` 被占用，插件会自动尝试 `38492-38495`。
如果本地端口通信全部失败，插件会自动把 Cookie 下载到系统下载目录下的 `YT下载器 Cookie Sync/browser_extension_cookies.txt`，桌面端会自动识别这个兜底文件。
